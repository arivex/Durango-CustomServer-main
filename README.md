## Features

- Custom server environment
- Local testing
- LAN multiplayer testing
- Custom server configuration
- Admin interface
- Custom launcher
- Development and experimentation tools

## Packages

### GamonServer

Server package for local/LAN testing.

### GamonClient

Client package used to connect to the custom server.

## Installation

See [USER_GUIDE.txt](USER_GUIDE.txt).

## Server

Default ports:

- Gateway: `8190`
- Game: `8191`

## LAN

For LAN testing, configure the client to use the
server computer's local IP address.

Example:

```text
http://192.168.1.50:8190
